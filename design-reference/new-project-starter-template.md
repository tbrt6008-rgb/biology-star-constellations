# 新 Web 项目启动模板

以后你新开一个 Web/UI 项目，可以直接复制这一段给 Codex。

## 给 Codex 的完整启动提示词

```text
我们要从素材库开始做一个 Web/UI 项目。

请按这个顺序工作：

1. 先读取项目结构。
2. 找到素材库里的图片和视频。
3. 建立或更新 design-reference 文件夹。
4. 生成素材清单 asset-inventory.md。
5. 生成项目简报 brief.md。
6. 根据素材提炼 style-guide.md。
7. 把参考图翻译成 ui-implementation-plan.md。
8. 再开始改代码。
9. 每轮改完运行 npm run build。
10. 用全局 playwright-cli 检查桌面端和手机端截图。

要求：

- 不直接复制参考图。
- 只学习色彩、布局、动效、组件气质。
- 保留项目现有功能。
- 优先改 CSS，必要时少量改 HTML，谨慎改 JS。
- 最后写一份复盘文档。
```

## 如果你已经有素材

```text
素材已经放在项目的 素材库 文件夹。
请先不要改代码，先帮我总结这些素材适合什么 UI 风格。
```

## 如果你想开始落地

```text
请按照 design-reference/style-guide.md 和 design-reference/ui-implementation-plan.md，
开始第一轮 UI 改造。
先做最安全、最明显的一块。
完成后构建，并用全局 playwright-cli 截桌面端和手机端。
```

## 如果你觉得页面不好看

不要只说：

```text
不好看。
```

要说：

```text
我觉得它的问题是：
1. 氛围不够像参考图
2. 卡片太普通
3. 手机端太挤
4. 字体层级不明显
5. 按钮不像同一个系统

请先分析原因，再给出修复方案，然后直接改。
```

## 如果你想让 Codex 自己判断

```text
请你按专业前端设计标准检查当前页面：
1. 视觉统一性
2. 信息层级
3. 手机端可用性
4. 交互状态
5. 文字溢出和遮挡
6. 是否符合 style-guide.md

发现问题请直接修复，并截图验证。
```
