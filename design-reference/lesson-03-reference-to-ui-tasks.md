# 第三步：把参考图翻译成可以改代码的 UI 任务

参考图不能直接变成代码。中间必须经过一次“翻译”。

## 翻译公式

```text
参考图里的感觉 -> 我的项目里的对象 -> 具体要改的代码位置
```

比如：

```text
深空探索感 -> 生物科学家星空轨道 -> 背景、首页标题、任务控制台、详情弹窗
```

## 用当前项目举例

### 1. 参考图里的顶部导航

参考图感觉：

- 干净
- 科技感
- 不抢主视觉
- 像控制台

变成你的项目：

- 顶部栏是“任务控制台”
- 搜索是“查找科学家档案”
- 星座筛选是“切换教材星区”
- 核心必考是“高优先级目标”

代码位置：

- `index.html` 里的 `#topbar`
- `src/styles.css` 里的 `#topbar`、`#search`、`.orb-btn`、`#core-btn`

### 2. 参考图里的大行星页面

参考图感觉：

- 一屏一个重点
- 右侧大星球
- 左侧少量文字
- 背景有空间纵深

变成你的项目：

- 科学家详情弹窗是一张“科学家任务档案”
- 右侧是科学家对应的星球视觉
- 左侧是人物、实验、教材和考法
- 信息不要堆满，要分层

代码位置：

- `index.html` 里的 `#poster-overlay`、`#poster-card`
- `src/styles.css` 里的 `.poster-col-left`、`.poster-col-right`、`.poster-planet-wrapper`、`.poster-info-scroll`
- `src/main.js` 里负责填充 `poster-info-body` 的逻辑

### 3. 参考图里的手机端竖卡

参考图感觉：

- 一张一张滑动
- 主视觉在上
- 文字少而清楚
- 卡片比例修长

变成你的项目：

- 手机端详情弹窗要像竖向科学家档案
- 星球视觉不能太大遮住文字
- 关闭按钮要容易点
- 筛选按钮要横向滑动

代码位置：

- `src/styles.css` 里的 `@media (max-width: 760px)`
- `#poster-card`
- `.poster-main-content`
- `.poster-planet-wrapper`
- `.poster-info-scroll`

### 4. 参考图里的背景氛围

参考图感觉：

- 暗色宇宙
- 蓝色地平线
- 光晕
- 漂浮物体

变成你的项目：

- 首页保留宇航员视频和星空画布
- 不把背景做得太亮
- 科学节点必须仍然清楚
- 背景服务知识图谱，不能抢走交互焦点

代码位置：

- `index.html` 里的 `#astronaut-bg`、`#canvas-section`
- `src/styles.css` 里的 `#canvas-section`、`#astronaut-bg`、`#home-intro`
- `src/main.js` 的 canvas 绘制逻辑

## 小白要记住的判断标准

改 UI 不是问“像不像参考图”，而是问：

1. 这个改动有没有保留项目功能？
2. 这个改动有没有更接近参考图的感觉？
3. 这个改动有没有服务高中生物课堂？
4. 这个改动有没有让手机端更好用？
5. 这个改动有没有通过构建和截图检查？

五个都满足，才算好改动。
