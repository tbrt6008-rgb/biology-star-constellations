# 项目简报

## 项目名称

高中生物科学家星空轨道

## 项目目标

做一个面向高中生物课堂展示的交互式 Web 应用。学生和老师可以在星空中浏览科学家、科学方法、教材模块和核心考点。

## 使用者

- 高中生物老师：课堂展示、讲科学史、串联教材模块。
- 高中学生：用更有画面感的方式记住科学家、实验方法和考点。

## 当前应用已有能力

- 星空画布
- 科学家筛选
- 搜索
- 核心考点筛选
- 科学家详情弹窗
- 科学方法弹窗
- Three.js 星球视觉
- 移动端适配基础

## 本轮设计目标

先不推翻现有项目。先建立一套“从素材到 UI 落地”的工作流，并把当前参考素材转化成可执行的设计规范。

## 设计关键词

- 深空
- 生物科学史
- 星座轨道
- 教材模块
- 任务档案
- 课堂展示
- 科技仪表盘
- 沉浸式知识图谱

## 不做什么

- 不直接复制 Pinterest 图片。
- 不把页面做成普通宣传落地页。
- 不把已有 `src/main.js` 和 `src/styles.css` 大拆大改。
- 不为了好看牺牲课堂可读性。
