## 1 · 项目背景与现状

### 1.1 项目定位
把高中生物科学史做成可投屏、可互动、可教学的"**宇宙任务控制台**"。90+ 位科学家 = 90 颗星球，按 5 本教材分入 5 个轨道（白羊·分子与细胞 / 巨蟹·遗传与进化 / 金牛·稳态与调节 / 双子·生物与环境 / 狮子·生物技术与工程）。

### 1.2 技术资产盘点
- ✅ Vue3 + Vite8 + Three.js + GSAP + Tailwind 4 构建完整
- ✅ Canvas 2D 5 轨道 + 5 教材主题色 + 90 张真实天文纹理（2.9MB/张）
- ✅ 完整业务闭环：开机序列 → 星图浏览 → 节点悬停 Tooltip → 海报详情 → 方法详情 → 搜索筛选 → 声音开关
- ✅ Playwright 历史截图 50+ 张（`.playwright-cli/`）
- ✅ 已有 v1 风格规范（`design-reference/style-guide.md` · 2026-04）

### 1.3 主要问题（视觉层 · 业务逻辑不变前提下）
| # | 问题 | 影响 |
|---|------|------|
| P1 | CSS 5081 行，token 与组件样式混杂，难维护 | 改一个 token 影响范围不可控 |
| P2 | 圆角、阴影、间距散落硬编码，缺统一阶梯 | 视觉碎片化，"5 个科学家 5 套样式" |
| P3 | 海报 / 方法模态框入场生硬，缺微动效 | 缺少"舰长下令"的仪式感 |
| P4 | 移动端断点不完整（只有简单缩放） | 手机无法顺畅使用 |
| P5 | 缺乏统一角标 / 扫描线 / 噪点装饰规范 | HUD 元素风格不统一 |
| P6 | 字号、行高、字距散落硬编码 | 课堂投屏排版一致性差 |
| P7 | 缺统一品牌色使用规则文档 | 新增组件时易破坏色彩平衡 |
| P8 | 无图片资源需求文档 | 后续功能扩展缺乏指引 |

## 2 · 设计目标

### 2.1 一句话目标
**把现有"功能完整但风格碎片化"的 UI，重构为"token 化、组件化、产品级"的设计系统**，全面达到 2026 年专业产品级视觉标准。

### 2.2 量化目标
| 维度 | 现状 | 目标 |
|------|------|------|
| CSS 行数 | 5081 | ≤ 4500（重构后减负） |
| Token 数量（语义化） | ~10 | ≥ 60（按 9 段式） |
| 圆角一致性 | 4 套混用 | 5 级阶梯统一 |
| 字号阶梯 | 8 级散落 | 10 级 token |
| 缓动曲线 | 6+ 种 | 收敛到 3 类预设 |
| 模态框入场时长 | 不统一 | 360ms `--ease-out-expo` 统一 |
| 移动端断点 | 1 个简单 | 3 断点完整（768 / 640 / 375） |
| Lighthouse Perf | 未知 | ≥ 90 |
| Lighthouse A11y | 未知 | ≥ 95 |
| 设计文档完整度 | v1 风格规范 | v2 完整四件套（DESIGN/Contract/Handoff/Asset） |

### 2.3 非目标（Non-goals）
- ❌ 不改业务逻辑（`loadData` / `bootSystemSequence` / `showPoster`）
- ❌ 不改 DOM 结构（id / class 全部保留）
- ❌ 不重做星球纹理（90 张已高品质）
- ❌ 不引入新字体、新依赖
- ❌ 不做账号 / 多人协作

## 3 · 用户体验提升点（Experience Upgrades）

### 3.1 视觉一致性（Visual Consistency）
- **5 教材色 → 语义化 token**：`--c-orb-1..5` 全局唯一来源；新增组件不再"凭感觉选色"
- **圆角 / 阴影 / 间距 → 阶梯化**：杜绝"5 个科学家 5 套样式"
- **玻璃面板统一**：所有浮层用 `--glass-bg` + `--glass-blur` + `--glass-border` 三件套

### 3.2 信息层级（Information Hierarchy）
- **字号阶梯 10 级**：从 11px（HUD 标签）到 clamp(2.5–4rem)（落地页 hero）
- **字距规则**：中文标题 0.06em，英文 HUD 0.12em
- **行高规则**：正文 1.65，标题 1.18
- **对比度审计**：所有正文 ≥ 4.5:1

### 3.3 动效专业度（Motion Craft）
- **入场统一**：模态框 360ms `--ease-out-expo` + 从画布 fly-out
- **微动效**：角标 4 角 L 形依次入场（60ms stagger）；扫描线 6s 线性循环
- **悬停高亮**：节点 hover 缓慢放大 1.08x + 主题色 glow
- **节奏克制**：避免弹跳 / 摇晃 / 旋转过速（投屏护眼）

### 3.4 仪式感（Ceremony）
- **开机序列**：沿用现有 BIOSPHERE ARCHIVE + 打字机（已优秀）
- **海报打开**：从画布位置 fly-out 到中心（GSAP 360ms）
- **模态框背景**：blur 8px + 暗化 40%（聚焦）
- **角标 + 扫描线入场**：增强"档案柜打开"的仪式

### 3.5 课堂可读性（Classroom Readability）
- **投屏优先**：暗背景 + 高对比文字 + 大字号主信息
- **中文为核心**：课堂核心信息 100% 中文
- **结构化**：所有参数表双行排列，标签 / 值 / 图标三列对齐
- **可打印**：海报背景可导出 PNG 讲义（场景 A1）

### 3.6 响应式（Responsive）
- **桌面 1280+**：当前布局，全功能
- **平板 768**：HUD 折叠为底部条；海报两栏自适应
- **手机 375**：HUD 隐藏到抽屉；海报全屏纵向；筛选按钮折叠到汉堡菜单

### 3.7 无障碍（Accessibility）
- **焦点环**：金色 2px + 4px halo（全组件已统一）
- **对比度**：≥ 4.5:1（审计）
- **键盘可达**：所有交互 Tab 可达，Enter/Space 触发
- **动效降级**：`prefers-reduced-motion: reduce` 关闭非必要动画

## 9 · 风险与缓解（Risk & Mitigation）

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| CSS 5081 行重构引入回归 | 中 | 双轨 token（v2 与 v1 并行）；逐阶段 Playwright 截图回归 |
| 新动效导致投屏眩晕 | 低 | 严守时长表（≤ 360ms 整屏）；`prefers-reduced-motion` 降级 |
| 移动端触摸交互缺失 | 中 | 补 `:active` + 长按手势；tooltip 改底部抽屉 |
| 与现有 token 同名冲突 | 低 | 新 token 加前缀（`--c-orb-` / `--text-hi`），不覆盖旧名 |
| 用户对风格"再调整"诉求 | 中 | 每阶段交付截图，邀请评审；及时回退 |
| 资源提供延迟影响 P3 进度 | 中 | 关键资源 C1 设硬截止 +14 天；非关键 A1/B1 可推迟 |
| 性能（动画多了导致掉帧） | 低 | 仅 transform / opacity；will-change 克制 |
