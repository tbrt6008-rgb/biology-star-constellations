# UI 验收清单

每次 Codex 说“完成了”，你可以用这张表检查。

## 基础检查

- [ ] 有没有说明改了哪些文件？
- [ ] 有没有运行 `npm run build`？
- [ ] 构建是否通过？
- [ ] 有没有桌面端截图？
- [ ] 有没有手机端截图？
- [ ] 有没有检查 `console error`？

## 视觉检查

- [ ] 是否符合 `style-guide.md`？
- [ ] 是否像一个完整系统，而不是零散拼接？
- [ ] 颜色是否统一？
- [ ] 按钮、标签、卡片是否同一套语言？
- [ ] 字体层级是否清楚？
- [ ] 重点信息是否第一眼能看到？

## 可用性检查

- [ ] 搜索框能不能用？
- [ ] 筛选按钮能不能点？
- [ ] 弹窗能不能打开？
- [ ] 弹窗能不能关闭？
- [ ] 手机端有没有横向溢出？
- [ ] 手机端按钮是否太小？
- [ ] 文字有没有被遮挡？

## 课堂场景检查

- [ ] 投屏时文字是否清楚？
- [ ] 氛围是否服务内容，而不是抢内容？
- [ ] 学生是否能快速知道当前页面讲什么？
- [ ] 老师是否能顺畅讲解？

## 不合格信号

如果出现这些情况，就不能算完成：

- 构建失败。
- 控制台有明显错误。
- 手机端文字重叠。
- 弹窗关不掉。
- 重要按钮点不到。
- 参考图被直接复制。
- 页面好看但内容看不清。
