# DESIGN.md — 高中生物科学家星空轨道 · 设计系统规范 v2

> **项目**：高中生物科学家星空轨道（Biology Starry Vault · Vue3 Canvas 可视化）
> **方向**：深空生物档案馆（Dark Sci-Fi · Mission Control for Biology）
> **方法论**：Open Design `reference-design-contract` 九段式（visual-theme → color → typography → spacing → layout → components → motion → voice → anti-patterns）
> **版本**：v2.0 · 2026-08-10 · 由产品经理主导，依据现有 `design-reference/style-guide.md` v1 升级

## 1 · Visual Theme & Atmosphere（视觉主题与氛围）

### 一句话定义
> **学生不是"看一篇文章"，而是"走进一座宇宙任务控制台"。**
> 在星空中点亮生物科学家的发现、方法和教材知识点；每一个交互都像一次舰长下令。

### 设计气质关键词
| 维度 | 表述 |
|------|------|
| **氛围** | Mission Control · Holographic HUD · 大气寂静 + 精密仪器感 |
| **节奏** | 大屏沉浸 · 单点精读（投屏可读 · 个人亦可玩） |
| **情绪** | 好奇 / 庄重 / 智能 / 不卖弄 · 不卡通 · 不冷漠 |
| **参照系** | Linear / Stripe / Apple Vision Pro / NASA Deep Space Network / 三体"古筝行动" |

### 视觉风格锚点
- **深色优先**：背景必须暗（投屏护眼 + 强化星点/霓虹对比）。
- **HUD 玻璃拟态**：面板 = "任务档案卡片"，不是"网页卡片"。
- **微噪点 + 扫描线**：每 8–12px 一道 1px 半透明扫描线，强化赛博质感（已有，保持）。
- **角标 L 形装饰**：四角 L 形 HUD 角标，已在 poster/method overlay 使用，需全组件统一。
- **真实天文纹理**：星球表面 = 真实等距圆柱投影（已有 90 张），保留。

### 不做什么
- ❌ 不要"网页 SaaS 模板感"（圆角大卡片 + 渐变按钮 + 阴影柔和）。
- ❌ 不要大量弹跳 / 旋转 / 抖动动画（投屏会眩晕）。
- ❌ 不要英文装饰压过中文内容（课堂核心必须中文）。
- ❌ 不要混用风格：不做"赛博 + 国风"、不做"星空 + 拟物"。

## 2 · Color（色彩系统）

### 2.1 背景梯度（页面环境）
| Token | 值 | 用途 |
|-------|-----|------|
| `--bg-deep` | `#060814` | 宇宙深空主背景 |
| `--bg-base` | `#0c0720` | 主画布底色（html/body） |
| `--bg-veil` | `#071526` | 顶部栏 / 面板玻璃底色 |

### 2.2 五教材主题色（语义化，不只是装饰）
> 每个轨道 = 一个星座 = 一种主色。**色相锁定，明度/饱和度按层次定。**

| Token | HSL | 含义 | 主用场景 |
|-------|-----|------|---------|
| `--c-orb-1` | `hsl(185 75% 58%)` `#2dd4e8` | 必修一 · 分子与细胞 · 青 | 轨道1节点、选中态、扫描线 |
| `--c-orb-2` | `hsl(42 88% 58%)` `#f0b030` | 必修二 · 遗传与进化 · 金 | 品牌强调、标题、CTA |
| `--c-orb-3` | `hsl(280 65% 68%)` `#c070f0` | 选必一 · 稳态与调节 · 紫 | 轨道3、神经网络 |
| `--c-orb-4` | `hsl(130 62% 55%)` `#50d080` | 选必二 · 生物与环境 · 绿 | 轨道4、生态 |
| `--c-orb-5` | `hsl(210 78% 62%)` `#4090ff` | 选必三 · 生物技术与工程 · 蓝 | 轨道5、技术流 |

> **规则**：同一时间一个区域最多 1 个主强调 + 1 个辅助强调；金色适合"标题/重点/课堂引导"，青色适合"交互/扫描/选中"。

### 2.3 文字 / 前景 / 状态
| Token | 值 | 用途 |
|-------|-----|------|
| `--text-hi` | `rgba(255 255 255 / .92)` | 标题 / 重点正文 |
| `--text-md` | `rgba(255 255 255 / .78)` | 正文 |
| `--text-lo` | `rgba(255 255 255 / .56)` | 辅助说明 |
| `--text-dim` | `rgba(255 255 255 / .38)` | 占位 / 标签 / 状态 |
| `--border-hi` | `rgba(255 255 255 / .14)` | 面板边框 |
| `--border-md` | `rgba(255 255 255 / .08)` | 分割线 |
| `--success` | `#50d080` | 操作成功 |
| `--warning` | `#f0b030` | 提醒 |
| `--danger` | `#ff7070` | 危险 / 警示红（核心按钮 hover） |

### 2.4 玻璃拟态面板
```css
--glass-bg:       rgba(8 12 28 / .72);
--glass-bg-strong:rgba(4 9 22 / .88);
--glass-border:   rgba(201 229 255 / .18);
--glass-blur:     blur(20px) saturate(180%);
```

### 2.5 对比度与无障碍
- 所有正文文字 ≥ 4.5:1（已满足 `--text-md` on `--bg-deep`）。
- 大字号（≥18px / 600w）≥ 3:1 即可。
- 焦点环：金色 2px + 4px 半透明外晕（已实现，全组件统一）。

## 3 · Typography（排版系统）

### 3.1 字体栈
| 用途 | 字体 | 备注 |
|------|------|------|
| **中文正文 / 标题** | `'Noto Sans SC'` 优先 → `'PingFang SC'` → `sans-serif` | 课堂投屏最易读 |
| **英文正文** | `'Inter'` 300/400/500/600 | 已在用 |
| **英文科技 / 数字** | `'Space Grotesk'` 400/600/700 | HUD 编号、坐标、状态 |
| **英文等宽 / 代码** | `'JetBrains Mono'` 400/700 | 遥测值、参数表 |
| **Display 大标题** | `'Space Grotesk'` 700（不做花体） | 投屏可见，避免衬线 |

> **规则**：标题可科技感，正文必须易读；不要英文装饰压中文；课堂核心必须中文。

### 3.2 字号阶梯（Type Scale）
> 采用 **Major Third (1.25) + 适度拉伸**，投屏/桌面双兼顾。

| `--fs-md` | .875 | 14 | 表格 / 输入框 |
| `--fs-base` | 1 | 16 | 正文 |
| `--fs-lg` | 1.125 | 18 | 次标题 |
| `--fs-xl` | 1.375 | 22 | 卡片标题 |

| `--fs-display` | clamp(2.5rem, 5vw, 4rem) | 40–64 | 落地页 hero |

### 3.3 行高 / 字距 / 段距
| 项 | 值 |
|-----|-----|
| 行高 正文 | 1.65 |
| 行高 标题 | 1.18 |
| 字距 大写 | 0.06em（中文标题）/ 0.12em（英文 HUD） |

### 4.2 圆角阶梯
| Token | px | 用途 |
|-------|----|------|
| `--r-xs` | 4 | 标签 / 徽章 |
| `--r-sm` | 6 | 按钮 / 输入框 |

### 4.3 栅格
- 桌面 ≥1280：12 列 · gutter 24 · max-width 1440
- 平板 768–1279：8 列 · gutter 20
- 手机 <768：单列纵向任务卡 · 边距 16

### 4.4 z-index 层级
```
0  : canvas / starfield

50 : nav 顶部栏
100: 浮动面板 (HUD telemetry)
200: tooltip
300: poster / method 模态框
999: 系统提示 / toast
```

## 6 · Components（组件规范）

> 全部组件沿用现有 DOM 结构与 class，不破坏业务逻辑。

### 6.1 按钮
| 状态 | 主按钮（CTA） | 次按钮（ghost） | 危险 |
|------|------------|--------------|------|
| **default** | bg `--c-orb-2`，文字 #0c0720，圆角 pill，shadow `--shadow-glow` | 透明 + border `--border-hi`，文字 `--text-md` | 透明 + border danger 40%，文字 danger |
| **hover** | translateY(-1px) + glow 增强 | bg 8% 白 | 同 left + bg danger 8% |
| **active** | translateY(0) scale(.98) | translateY(0) scale(.98) | translateY(0) scale(.98) |
| **disabled** | opacity .4, cursor not-allowed | opacity .3 | opacity .3 |
| **focus-visible** | 金色 2px outline + 4px halo | 同 | 同 |

### 6.2 输入框（#search）
- 默认：bg 7% 白 + border 14% 白，圆角 pill，padding 5px 14px 5px 34px
- focus：bg 12% 白 + border 32% 白 + 金色 3px halo + 18px 金色外发光 + width 180→210px（**已有，强化动效曲线**）
- placeholder：`--text-dim`
- 图标：左侧绝对定位，`--text-dim`

### 6.3 筛选胶囊（.orb-btn[data-orbit]）
- 默认：bg 4% 白 + border 12% 白，文字 `--text-md`，圆角 pill
- hover：bg 8% 白，translateY(-1px)
- active（选中态）：bg 15% 主题色 + border 50% 主题色 + 10px 主题色 glow + 文字 #fff + 600w
- 五轨道使用各自 `--c-orb-N`，"全部"按钮使用 `--text-md` + 白光

### 6.4 海报卡片（#poster-card）
- 玻璃拟态：`--glass-bg` + `--glass-blur` + `--glass-border`
- 圆角 16；外发光 `--shadow-card`
- L 形角标：4 个 18×18 SVG 边框，`--c-orb-2` 描边
- 顶部扫描线：1px 高，linear-gradient `--c-orb-2` 30%→0%，**自上而下循环** 6s

### 6.5 表格（retro-table）
- 3 列 / 6 行 / 双色行（4% 白 / 透明交替）
- 标签列 `--text-dim`，值列 `--text-hi`，图标列 18px emoji
- cell padding 8/12，圆角 6，分隔线 1px `--border-md`

### 6.6 HUD 遥测面板（#hud-telemetry）
- 玻璃面板，360×auto，右上 24px 偏移
- header：12px Space Grotesk 600，大写，字距 .12em，色 `--c-orb-2`
- 行：label 11px dim / value 13px hi，gap 12
- 扫描进度条：4px 高，bg 12% 白 + fill 金色 4s 循环

### 6.7 Tooltip
- 跟随鼠标，offset 14,14
- 玻璃面板 240×auto，padding 12
- 头部双列：SECTOR / COORD（11px dim）
- 名称：18px Space Grotesk 600，色 `--c-orb-N`（按轨道）
- 底部双列：STATUS · SYS_TELEMETRY

### 6.8 顶部控制栏（#topbar）
- 高 54px，玻璃 bg 55%，blur 20px saturate 180%
- 边框：底 1px 8% 白
- 内阴影 + 外阴影：inset 1px 0 4% 白 / 0 4px 24px 黑 35%

## 7 · Motion & Interaction（动效规范）

### 7.1 缓动曲线（已定义，沿用）
```css
--ease-premium:   cubic-bezier(.16, 1, .3, 1);    /* 默认出场/进场 */
--ease-out-expo:  cubic-bezier(.19, 1, .22, 1);   /* 卡片浮起 */
--ease-in-out-soft: cubic-bezier(.65, 0, .35, 1);  /* 双向往返 */
```

### 7.2 时长规范
| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮 hover/active | 180ms | --ease-premium |
| 搜索框 focus | 220ms | --ease-premium |
| 模态框打开 | 360ms | --ease-out-expo |
| 模态框关闭 | 240ms | --ease-premium |
| Tooltip 显隐 | 160ms in / 120ms out | --ease-premium |
| 顶部栏 scroll 状态 | 200ms | --ease-premium |
| 节点 hover 高亮 | 220ms | --ease-premium |
| 扫描线 / 卫星旋转 | 6–12s linear | infinite |

### 7.3 必备交互态（缺一不可）
- ✅ hover / focus-visible / active / disabled / loading（已覆盖大部分）
- ⏳ 海报打开：从画布位置 fly-out 到中心 360ms（GSAP 实现）
- ⏳ 模态框背景：模糊背景 8px + 暗化 40%
- ⏳ 星球节点：hover 缓慢放大 1.08x + 主题色 glow 增强
- ⏳ 筛选切换：canvas 内节点重排 fade-in stagger 30ms

### 7.4 适合的微动效
- 星点闪烁（2–4s 循环，已实现）
- 轨道卫星绕行（6–12s linear，已实现）
- HUD 扫描条循环（4s linear）
- 角标 L 入场：从角向中心展开（240ms stagger 60ms）

### 7.5 必须避免
- ❌ 大面积背景模糊动画（GPU 紧张）
- ❌ 文字抖动 / 弹跳（投屏眩晕）
- ❌ 旋转速度 > 1 圈/3 秒
- ❌ 任何 ≥ 500ms 的整屏过渡

## 8 · Voice & Brand（品牌语态）

### 8.1 中文文案规则
| 场景 | 风格 |
|------|------|
| 标题 | 简洁、庄重、有想象空间：「星空穹顶」「遗传与进化·巨蟹座」 |
| 副标题 | 一句话解释 + 情绪：「在浩瀚星空中点亮生命奥秘」 |
| 按钮 | 动词 + 对象：「点亮档案」「进入浩瀚星空」 |
| 标签 | 名词短语、英文缩写并列：「COSMIC TIME · 宇宙时」 |
| 状态 | 短促：「SYS_ACTIVE // NORMAL」 |

### 8.2 英文文案规则
- 全部大写 + 字距 .12em（科技感）
- 缩写优先：RA/DEC, MAG, COG, MOD, CST, SYS
- 单位：使用国际标准（dB, ly, AU）
- 标点用 `//` 分隔字段

### 8.3 品牌口令
- **主推**：STARRY VAULT · 高中生物科学家星空轨道
- **副推**：深空生物档案馆 · Mission Control for Biology
- **价值承诺**：把科学家的发现，变成你星图上的星辰

## 9 · Anti-patterns（反模式 · 必须避免）

| 反模式 | 替代 |
|--------|------|
| 圆角 > 20px 的卡片 | 圆角 8–16px，保留 HUD 严肃感 |
| 多重阴影 + 大模糊 | 单层精准 shadow + 主题色 glow |
| 同区域用 ≥ 3 种主色 | ≤ 1 主 + 1 辅 |
| 英文装饰 > 中文信息 | 课堂信息必中文 |
| 弹跳 / 摇晃 / 旋转装饰 | 统一 6 类缓动 + 时长表 |
| 卡片嵌套卡片 | 单层卡片 + 内部 grid 分区 |
| emoji 当图标 | 几何 / SVG / emoji 作 accent 限 ≤ 18px |
| 阴影 + 渐变 + 模糊三重叠加 | 单手段表达 |
| 透明面板叠加导致阅读困难 | 文字层加 `--glass-bg-strong` |
| 中文小 < 13px / 英文小 < 11px | 字号下限：`--fs-sm` 13 / `--fs-xs` 11 |
| 渐变文字 | 实色 + 主题色 |
| 把 HUD 装饰元素当主视觉 | 主视觉 = 标题 + 星球；HUD 占 10% |
| 不同视图用不同圆角 | 圆角走 5 级阶梯 |
| 不同动效用不同缓动 | 6 类曲线（已上） |

## 10 · 实施优先级（迁移路线图）

> **不动业务逻辑 · 不改 DOM 结构 · 仅重构 CSS token / 组件类 / 动效。**

| 阶段 | 内容 | 验收 |
|------|------|------|
| **P0 立即** | 抽取本规范 §2–§4 的 token 到 `:root`，与现有变量双轨并行；旧 var alias 保留 | `npm run build` 通过 |
| **P1 一周** | 顶栏 / HUD / Tooltip / 按钮 / 输入框 应用规范 §6 | 桌面 1280 截图对比 |
| **P2 一周** | 海报 / 方法 模态框应用规范 §6 + 角标/扫描线入场动效 | 桌面 + 平板截图 |
| **P3 一周** | 响应式 / 移动端布局 + 触摸替代方案 | 手机 375 / 平板 768 截图 |
| **P4 持续** | 微动效打磨 + 无障碍审计 + 性能（CLS / FCP） | Lighthouse ≥ 90 |

> 每阶段 `npm run build` + Playwright 截图回归（已有 `.playwright-cli/` 套件）。
