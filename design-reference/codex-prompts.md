# 你以后可以直接复制给 Codex 的话

## 1. 让 Codex 先看素材

```text
请先读取当前项目的 design-reference 文件夹和 素材库 文件夹。
你先不要改代码，只总结这些素材适合形成什么 UI 风格。
请输出：视觉方向、色彩、字体、布局、组件、动效、不能照抄的风险。
```

## 2. 让 Codex 生成设计规范

```text
请根据素材库和项目目标，更新 design-reference/style-guide.md。
要求：
1. 只提炼风格，不复制原图
2. 规则要能直接指导 Vue/CSS 实现
3. 必须考虑桌面端和手机端
4. 必须考虑课堂投屏可读性
```

## 3. 让 Codex 开始改页面

```text
请按照 design-reference/style-guide.md 和 implementation-checklist.md，
对当前 Vue 项目进行第一轮 UI 改造。
要求：
1. 优先保留现有功能
2. 优先改 src/styles.css 和必要的 index.html
3. 不大规模重构 src/main.js
4. 完成后运行 npm run build
5. 启动本地服务并检查桌面端、手机端截图
```

## 4. 让 Codex 检查效果

```text
请打开本地页面，分别检查桌面端和手机端。
重点看：
1. 文字有没有溢出
2. 按钮能不能点
3. 详情弹窗有没有遮挡
4. 星空画布有没有正常显示
5. 整体是否符合 style-guide.md
发现问题请直接修复。
```

## 5. 你表达审美时可以这样说

```text
我喜欢这张图的：
- 背景氛围
- 卡片比例
- 字体感觉
- 发光边框
- 动效节奏

我不想要：
- 直接照抄英文
- 太花导致看不清
- 普通网页卡片感
- 手机端挤在一起
```
