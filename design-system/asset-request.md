## 3. 风格统一规则（重要 · 请严格遵守）

### 3.1 色板（必须从中取色）
```
深空：#060814 / #0c0720 / #071526
玻璃：rgba(8 12 28 / .72)
金：#f0b030
青：#2dd4e8
紫：#c070f0
绿：#50d080
蓝：#4090ff
文字：rgba(255 255 255 / .78 ~ .92)
边框：rgba(255 255 255 / .08 ~ .14)
```

### 3.2 构图原则
- **留白率 ≥ 40%**（投屏可读）
- **HUD 装饰 ≤ 10%** 画面（克制）
- **主视觉 = 标题 + 星球 / 主体**，其余辅助
- **避免**：渐变文字 / 多重阴影 / 高饱和 / 卡通脸 / 写实照片

### 3.3 字体规则（若含文字）
- 中文：`Noto Sans SC` 600/700
- 英文：`Space Grotesk` 600/700 · 全大写 · 字距 .12em

## 4. 提供方式
