# 第一版风格规范

## 视觉方向

方向名称：深空生物档案馆

核心感觉：学生进入一个宇宙任务控制台，在星空中点亮生物科学家的发现、方法和教材知识点。

## 色彩

主背景：

- 深黑蓝：`#060814`
- 深紫黑：`#0c0720`
- 星云蓝黑：`#071526`

主强调色：

- 生物青：`#2dd4e8`
- 探索金：`#f0b030`
- 轨道蓝：`#4090ff`

辅助强调色：

- 遗传紫：`#c070f0`
- 生态绿：`#50d080`
- 警示红：`#ff7070`

使用规则：

- 背景必须暗，文字必须清楚。
- 一个区域最多使用 1 个主强调色和 1 个辅助强调色。
- 金色适合标题、重要状态和课堂引导。
- 青色适合交互、扫描线、选中态和科技边框。

## 字体气质

中文：

- 优先清晰、现代、适合课堂投屏的无衬线字体。
- 标题可以更有科技感，但正文必须易读。

英文和数字：

- 可使用窄体、等宽或科技感字体，适合编号、坐标、状态、年份。

文字规则：

- 不要大段英文装饰压过中文内容。
- 课堂核心信息必须用中文表达。
- 小字只用于状态、坐标、标签，不承载关键知识点。

## 布局

整体布局参考：

- 首屏是沉浸式星空或宇宙画布。
- 信息面板像“任务档案”，不要像普通卡片。
- 重要对象使用大图、大标题、少量高价值文字。
- 移动端用纵向任务卡片，保持高比例视觉冲击。

页面层级：

1. 背景氛围：星空、轨道、光晕、粒子。
2. 主交互层：星点、科学家节点、星座模块。
3. 信息层：搜索、筛选、状态、详情。
4. 课堂讲解层：重点、实验方法、教材联系。

## 组件规则

顶部栏：

- 半透明玻璃背景。
- 高度紧凑，不能遮挡主画布。
- 筛选按钮要像控制台按钮，不要像普通网页按钮。

详情弹窗：

- 像科学家任务档案。
- 左侧或上方放强视觉，右侧或下方放结构化知识。
- 重要信息要有标签，例如时代、国籍、教材模块、核心程度。

卡片：

- 圆角控制在 8px 左右。
- 可使用细边框、内发光、扫描线、噪点。
- 不要卡片套卡片。

按钮：

- 主要按钮使用明确图标或短文本。
- 有 hover、active、disabled 三种状态。
- 选中态要明显，但不能过亮。

## 动效

适合使用：

- 星点轻微闪烁
- 轨道缓慢运动
- 面板淡入
- 详情打开时轻微推进
- 鼠标悬停时局部高亮

避免使用：

- 大量弹跳动画
- 过快的旋转
- 干扰阅读的文字动画
- 会让课堂投屏眩晕的镜头运动

## 落地原则

- 先保留现有功能，再增强风格。
- 先改 CSS 和少量 DOM，再考虑组件化。
- 每改一个阶段都要运行 `npm run build`。
- 如果做视觉大改，要用浏览器检查桌面端和手机端截图。
